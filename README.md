# Tuana Sanat Kulübü

Tuana Sanat Kulübü'nün web sitesi (tek sayfa, düz HTML/CSS/JS).

- Test adresi: https://tuanasanatkulubu.github.io
- Ana dosya: `index.html`, görseller `img/` klasöründe.
